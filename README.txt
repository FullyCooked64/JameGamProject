Hi!!!! This is the code and assets from my game, just the default Unity export for Unity projects into GitHub
for my game in the Jame Gam Game Jam Lil' Car

It's a game set on a small desktop car that suddenly got occupied by a person turned small by a mysterious cube! 

It features clean toon-outlined pixel art graphics over smooth low poly models.

CONTROLS - WASD for movement
Win by reaching the mysterious cube in a time trial style race and beat your last time!
